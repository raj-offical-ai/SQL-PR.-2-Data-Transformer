# 🔄 Data Transformer — SQL Project

## 📌 Project Overview
Data Transformer is a MySQL-based project that demonstrates data analysis, data transformation, relational joins, and business logic using SQL queries.

## 🛠️ Technologies Used
- MySQL
- SQL
- Relational Database Management
- Window Functions

## 🗄️ Database Tables
1. **Customers** — Customer details and registration dates.
2. **Orders** — Order dates, amounts, and customer relationships.
3. **Employees** — Employee details, departments, and salaries.

## ⚙️ Key Features
This project implements 17 SQL operations, including:

- INNER, LEFT, RIGHT, and simulated FULL OUTER JOIN.
- Subqueries to find above-average orders and salaries.
- Date extraction, difference, and formatting.
- String concatenation, replacement, case conversion, and trimming.
- Running totals and order ranking.
- Conditional discount calculation.
- Employee salary classification using `CASE`.

## 🚀 How to Run
1. Install MySQL Server and MySQL Workbench.
2. Open a new SQL query tab.
3. Execute the `DATA_TRANSFORMER.sql` script.
4. View the results of each query.

**Note:** The script drops and recreates its tables when rerun. Use a test database to avoid losing existing data.

## 📊 Sample Dataset
- 4 Customers
- 6 Orders
- 5 Employees
